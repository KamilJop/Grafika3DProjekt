Detailed Description

Represents an oscillating moving part of a clock (e.g., pendulum or hand).

The ClockMovingPart class extends Entity and provides:

  • Automatic back‑and‑forth rotation between two angles
  • Adjustable rotation speed and limits
  • Simple oscillation logic for decorative or puzzle elements

void ClockMovingPart::Update ( float deltaTime)
overridevirtual

Updates the clock part each frame.

Updates the rotation of the clock’s moving part.

Oscillates the rotation between minimumAngle and maximumAngle using rotationSpeed.
Creates a smooth ticking or swinging motion.

Parameters
deltaTimeTime elapsed since last frame.

This function oscillates the rotation of the clock component between a minimum and maximum angle, creating a ticking or swinging motion.

Behavior:

  • If direction is true, the part rotates forward.
  • If the rotation exceeds maximumAngle, direction reverses.
  • If direction is false, the part rotates backward.
  • If the rotation goes below minimumAngle, direction reverses.
