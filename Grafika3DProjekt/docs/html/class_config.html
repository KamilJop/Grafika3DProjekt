Detailed Description

Manages game configuration settings.

This class handles reading and writing configuration settings to a file (config.txt). It uses the Singleton pattern so there is only one instance of the configuration in the program.

◆ CreateDefaultConfig()

void Config::CreateDefaultConfig ( )
protected

Creates a default configuration and writes it to the file.

Creates a default configuration and saves it to the config file.

Called if the config file does not exist or cannot be read.

Default settings:

  • screenWidth = 2560, screenHeight = 1440
  • musicVolume = 0.5, sfxVolume = 0.5
  • fullscreen = false, showFPS = false, antiAliasing = true
  • outlineColor = red (1,0,0), highlightColor = green (0,1,0)
