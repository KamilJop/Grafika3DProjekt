Detailed Description

Represents an interactable door that can be locked, unlocked, opened, and closed.

The Door class provides:

  • Lock/unlock logic using key tags
  • Smooth opening/closing animation
  • Shaking animation when trying to open a locked door
  • Sound effects for all door states
  • Optional door frame entity for enabling/disabling collisions

Handles player interaction with the door.

Behavior:

  • If locked: checks for correct key, otherwise plays locked animation
  • If unlocked: toggles open/close state
  • Plays appropriate sound effects
Parameters
playerInventoryPointer to the player's inventory.

Behavior:

  • If the door is animating or shaking, ignore interaction
  • If locked:
    • If player holds the correct key: unlock the door
    • Otherwise: play locked sound and shake animation
  • If unlocked:
    • Toggle open/close state
    • Play appropriate sound
    • Enable/disable door frame collisions
